# Hamster Flip Test — Unity Android ARM64

A tiny procedural Unity 2022.3 project made to test the complete phone-only pipeline:

- 3D hamster built from Unity primitives
- trampoline with automatic bounce
- one large mobile FLIP button
- controlled 360-degree front flip
- Android APK
- IL2CPP
- ARM64 only

The build method is `HamsterFlip.Editor.AndroidBuilder.BuildArm64FromCommandLine`.
The expected artifact is `Build/Android/HamsterFlip_ARM64.apk`.
